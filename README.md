# Code Wars — Desafios de Lógica de Programação

Este repositório reúne desafios de lógica de programação para praticar e melhorar suas habilidades algorítmicas. Cada desafio é desenvolvido em uma branch separada, permitindo que cada solução seja trabalhada de forma isolada e comparável.

## Objetivo

- Fornecer um espaço organizado para resolver desafios de lógica.
- Permitir que cada contribuição (branch) contenha um desafio e sua solução.

## Como funciona

- Cada desafio deve ter sua própria branch no formato `desafio/<nome-do-desafio>`.
- A branch principal (`main`) deve permanecer limpa e apenas integrar soluções revisadas, se desejado.
- Dentro da branch do desafio, inclua uma pasta com o enunciado (`problema.md`), a solução em código, e testes ou exemplos de execução.

## Estrutura sugerida

- `desafio/nome-do-desafio/`
  - `problema.md` — enunciado do desafio
  - `solucao/` — código da solução (subpasta por linguagem opcional)
  - `tests/` — testes ou exemplos de entrada/saída
